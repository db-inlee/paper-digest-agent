## 방법론
**Perception Layer**
다양한 모달리티의 원시 데이터를 직접 인식하여 증거를 계층적으로 조직한다.
- **입력**: 원시 데이터
- **출력**: 계층적으로 조직된 증거
- **구현 힌트**: 각 증거 가족 내에서 특정 모달리티가 정의되며, 에이전트는 등록된 도구를 사용하여 이를 검사한다.
- **역할**: novel (Evidence: §4.1 Perception layer)

**Ideation Agent**
ReAct 루프를 통해 발견 프로세스를 자동으로 시퀀싱하여 구체적이고 새로운, 반증 가능한 질문을 공식화한다.
- **입력**: 자료 인벤토리, 문헌 검색 결과
- **출력**: 최종화된 연구 질문
- **구현 힌트**: 최소 5개의 후보 아이디어를 개발하고, 각 아이디어의 참신성 위험과 실행 가능성을 평가한다.
- **역할**: novel (Evidence: §4.2 Ideation)

**Experiment Agent**
최종화된 아이디어를 방법론적 설계로 번역하고 반복적인 코드 생성을 통해 구현한다.
- **입력**: 최종화된 연구 질문
- **출력**: 실험 결과
- **구현 힌트**: 실험 설계에 최소 4개의 분석을 통합하여 주요 가설 테스트와 필수적인 통제 요소를 결합한다.
- **역할**: novel (Evidence: §4.3 Experiment)

**Writeup Agent**
실행 기록에 의해 지원되는 주장만을 선택, 근거화, 보고하여 최종 논문을 작성한다.
- **입력**: 실험 결과
- **출력**: 최종 논문
- **구현 힌트**: 각 섹션은 필요한 구조화된 실험 기록의 슬라이스에서만 확장된다.
- **역할**: novel (Evidence: §4.4 Writeup)
