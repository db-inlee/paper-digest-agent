## 문제 정의
비주얼 그라운딩(visual grounding)을 통해 시각적 사고를 개선하는 문제를 다룬다. 기존의 비전-언어 모델(VLMs)은 자연어 추론을 생성할 수 있지만, 지원하는 이미지 영역을 명시적으로 나타내지 않아 검증이 어렵고 감독하기 어렵다.

**기존 방법의 한계**: 기존의 자연어 추론은 이미지 영역을 명시적으로 식별하지 않기 때문에 검증과 감독이 어렵다.

### Delta 1: 추론 전략
- **기존**: 기존의 비전-언어 모델은 자연어 추론을 생성하지만 명시적인 비주얼 그라운딩을 제공하지 않음
- **변경**: Visually Grounded Thinking을 통해 자연어 추론과 명시적인 비주얼 그라운딩을 교차하여 수행
- **이유**: 중요한 시각적 객체를 참조할 때마다 좌표 기반의 그라운딩 태그를 출력하여 이미지에서 참조된 객체를 식별할 수 있음 

### Delta 2: 데이터 생성
- **기존**: 해당 영역에 특화된 데이터 생성 파이프라인 없음

- **이유**: SAM3 기반의 에이전트를 사용하여 고품질 객체 마스크를 추출하고, 포인트 및 박스 모드의 그라운딩 추론 데이터를 생성함 

### Delta 3: 학습 전략
- **기존**: 정확한 그라운딩을 장려하는 강화 학습 기법 없음
- **변경**: Grounding-aware Reinforcement Learning을 통해 정답의 정확성과 시각적 객체의 정확한 그라운딩을 동시에 장려
- **이유**: 정확한 그라운딩을 수행하는 모델을 학습시킬 수 있음
