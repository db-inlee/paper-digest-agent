기존의 라우팅 접근 방식은 입력 수준의 라우터가 진화하는 작업 요구 사항을 무시하고, RL로 훈련된 오케스트레이터는 적응 비용이 높고 라우팅 붕괴에 취약하다. SkillOrchestra는 스킬 인식 오케스트레이션을 통해 이러한 문제를 해결하고자 한다.

**기존 방법의 한계**: 기존의 라우팅 접근 방식은 입력 수준의 라우터가 진화하는 작업 요구 사항을 무시하고, RL로 훈련된 오케스트레이터는 적응 비용이 높고 라우팅 붕괴에 취약하다.

## 핵심 기여

## 방법론
### Skill Handbook
재사용 가능한 실행 지식을 캡처하는 구조화된 스킬 핸드북을 학습하여 모드 선택 및 에이전트 라우팅을 안내한다.
- **입력**: Execution traces
- **출력**: Mode-level execution insights, Fine-grained skills, Agent profiles
- **구현 힌트**: 핸드북은 모드 선택 통찰력, 스킬, 에이전트 프로필을 저장하는 그래프로 볼 수 있다.

### Mode Selection
현재 상호작용 상태에 따라 적절한 운영 모드를 선택한다.
- **입력**: Current state
- **출력**: Operational mode
- **구현 힌트**: 모드 정책 πmode는 상호작용 상태와 핸드북에 저장된 모드 수준 라우팅 메타데이터를 기반으로 현재 운영 모드를 선택한다.

### Competence-Aware Agent Routing
선택된 모드에 따라 관련 스킬을 식별하고, 스킬 집합에 대한 역량 추정치를 집계하여 에이전트를 선택한다.
- **입력**: Selected mode, Relevant skills
- **출력**: Selected agent
- **구현 힌트**: 각 에이전트에 대해 스킬 집합에 대한 역량 추정치를 집계하고 실행 비용과 비교하여 에이전트를 선택한다.

### 3. ManCAR: Manifold-Constrained Latent Reasoning with Adaptive Test-Time Computation for Sequential Recommendation ⭐⭐⭐⭐

**arXiv**: [2602.20093](https://arxiv.org/abs/2602.20093)
**PDF**: [다운로드](https://arxiv.org/pdf/2602.20093.pdf)
**GitHub**: [https://github.com/FuCongResearchSquad/ManCAR](https://github.com/FuCongResearchSquad/ManCAR)
**매칭 키워드**: reasoning

## 왜 이 논문인가?
총점: 11/15

🎯 점수 상세:
  - 실용성 (Practicality): 4/5
  - 구현 가능성 (Codeability): 3/5
  - 신뢰도 (Signal): 4/5

💡 평가 근거:
이 논문은 순차 추천 시스템에서의 잠재적 드리프트 문제를 해결하기 위한 매니폴드 제약을 도입하고, 적응적 테스트 종료 기준을 설계하여 실제 문제 해결 가능성을 높인다. 이러한 접근은 실용적인 응용 가능성이 높아 보인다.

**주요 강점**: 매니폴드 제약을 통한 잠재적 추론 개선과 적응적 종료 기준 설계가 주요 강점이다.
**주요 우려**: 기존 모델들과의 비교에서 실제 성능 향상이 얼마나 이루어졌는지에 대한 명확한 증거가 부족할 수 있다.

## 한 줄 요약
이 논문은 기존의 순차 추천 시스템에서 발생하는 잠재적 드리프트 문제를 해결하기 위해 매니폴드 제약을 통한 잠재적 추론과 적응적 테스트 종료를 도입하여 개선한다.

## 문제 정의
기존의 순차 추천 시스템에서 발생하는 잠재적 드리프트(latent drift) 문제를 해결하기 위해, 사용자의 최근 행동에 기반한 협업적 이웃을 활용하여 유효한 매니폴드(manifold) 내에서 잠재적 추론을 진행하는 방법을 제안한다.

**기존 방법의 한계**: 기존 방법들은 중간 추론 상태의 진화를 명시적으로 제한하지 않아, 잠재적 드리프트가 발생할 수 있다.

## 핵심 기여
- ManCAR는 협업적 이웃을 활용하여 잠재적 드리프트를 방지하는 매니폴드 제약을 통해 잠재적 추론을 안내한다.
- ManCAR는 적응적 테스트 시점 종료를 통해 과도한 세분화를 피하고, 예측 분포가 안정화될 때까지 추론을 진행한다.

## 방법론
### Manifold-Constrained Latent Reasoning
사용자의 최근 상호작용을 기반으로 한 협업적 이웃을 활용하여 잠재적 추론 궤적을 유효한 매니폴드 내에서 제한한다.
- **입력**: 사용자의 최근 상호작용
- **출력**: 유효한 매니폴드 내의 잠재적 추론 궤적
- **구현 힌트**: 그래프 조건부 후보 세트를 사용하여 잠재적 추론 궤적을 제한

### Variational Training Objective
잠재적 추론을 중간 의도 변수에 대한 근사 추론으로 취급하여 ELBO와 유사한 목표를 도출한다.
- **입력**: 사용자 상호작용 이력
